# Finkskore
This is a browser based web app for scoring games of Finska.
It lets users add players, start a game, record scores and track the player positions.
The game ends when a player reaches a score of exactly 50 points.

It uses Vue3

## Bash Commands
- npm run build: Build the project

## Live Legacy example
The legacy version of this app is viewable at https://finskore.com
